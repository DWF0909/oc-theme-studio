# OC Theme Studio 2.0

- First GitHub release of the application package
- Includes three sample themes: Midnight Blue, Graphite Mono, and Aurora
- Includes Standard, Minimal, and Linux distribution icon presets
- Requires macOS 11 or later
- Intel x86_64 build; no native Apple silicon build is included
- The app uses an ad hoc signature and has no Developer ID Team ID
- DMG only; source code and build files are not included
