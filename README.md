# OC Theme Studio

OC Theme Studio 是一款 macOS 原生应用，用于整理和制作 OpenCore 启动选择器主题。当前发行包内含 Midnight Blue、Graphite Mono、Aurora 三套示例主题，以及标准、极简和多 Linux 发行版图标预设。

> 本仓库目前仅发布应用程序 DMG，不包含 Swift 源码或项目构建文件。

## 下载

从 [Releases](https://github.com/DWF0909/oc-theme-studio/releases/latest) 下载 `OC-Theme-Studio-2.0.dmg`。

## 安装

1. 打开下载的 DMG。
2. 将 `OC Theme Studio.app` 拖到“应用程序”文件夹。
3. 从“应用程序”启动 OC Theme Studio。

## 系统要求与发行包信息

- macOS 11 或更高版本
- 当前二进制为 Intel x86_64 架构；未提供 Apple Silicon 原生版本
- 应用版本：2.0
- DMG 内应用采用 ad-hoc 签名（没有 Developer ID Team ID）。首次打开时请确认来源可信；macOS 可能显示安全提示
