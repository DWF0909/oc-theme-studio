# OC Theme Studio

OC Theme Studio is a native macOS utility for creating and managing OpenCore boot picker themes. This release includes three sample themes—Midnight Blue, Graphite Mono, and Aurora—plus Standard, Minimal, and Linux distribution icon presets.

> This repository provides the application DMG only. Swift source code and build files are not included.

## Download

Download `OC-Theme-Studio-2.0.dmg` from the [latest GitHub release](https://github.com/Piosn/oc-theme-studio/releases/latest).

## Installation

1. Open the downloaded DMG.
2. Drag `OC Theme Studio.app` to the Applications folder.
3. Launch OC Theme Studio from Applications.

## System Requirements and Package Details

- macOS 11 or later
- The included application is built for Intel x86_64. No native Apple silicon build is included.
- Application version: 2.0
- The app uses an ad hoc signature and has no Developer ID Team ID. macOS may show a security notice. Verify the download source before opening it.
